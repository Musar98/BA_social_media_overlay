# 📱 Instagram Video Overlay – through Learned Parametric Emotion Editing of Images

This project injects a custom AI-powered overlay engine into Instagram using an Android `WebView`. 

It consists of three main parts:

1. **Android host app (Kotlin / Jetpack Compose)**
2. **AI Overlay Engine (TypeScript + Vite)** (ai-overlay-engine/README.md)
3. **AI Worker (Typescript + Vite)** (inside ai-overlay-engine)

---

## 🧠 Overview

The app loads Instagram inside a `WebView` and injects custom JavaScript bundles into the page at runtime.

The injected script:
* Observe Instagram video elements
* Run AI-based predictions (via ONNX/WASM) through a web worker (bundled as separate js file)
* Dynamically applies visual transformations to videos with the parameters generated by the AI model

## 🏗 Architecture

```
Android App (Kotlin)
│
├── WebView (Instagram)
│   ├── Loads https://www.instagram.com
│   ├── Intercepts requests for local AI assets
│   └── Injects AI Overlay Engine (JS)
│
├── Asset Loader (/_onnx/)
│   ├── Serves ONNX Runtime Web + models from Android assets
│   └── Enables WebView access to local AI inference files
│
├── assets/
│   ├── AI Overlay Engine (IIFE bundle)
│   │   ├── Built with Vite (TypeScript)
│   │   ├── Runs inside Instagram DOM
│   │   └── Applies AI-driven video transformations
│   │
│   ├── AI Worker (IIFE bundle)
│   │   ├── Built with Vite (TypeScript)
│   │   ├── Runs inside Instagram DOM
│   │   └── Runs AI parameter prediction for video transformations
│   │
│   └── ONNX Runtime Bundle
│       ├── ort.min.js + supporting ONNX Runtime Web files
│       ├── models/ → AI model files used for inference
│       ├── Stored in Android assets
│       └── Loaded at runtime by ai-overlay-engine
```

### 🔌 Script Injection Flow

The injection happens after each page load:

```kotlin
override fun onPageFinished(view: WebView?, url: String?) {
    if (url != null && url != lastInjectedUrl) {
        lastInjectedUrl = url
        injectAiOverlayEngine(this@apply)
    }
}
```

The engine is loaded from app assets inside:
`main/java/assets/AiOverlayInjector` 
```kotlin
val script = webView.context.assets
   .open("ai-overlay-engine/ai-overlay-engine.iife.js")
   .bufferedReader()
   .use { it.readText() }
```

---

### 📦 Local Asset Serving (ONNX / WASM)

We expose local AI model files under:

`main/java/assets/AssetRouting`
```
https://www.instagram.com/_onnx/...
```

Handled via:

`main/java/webview/WebviewClientFactory`
```kotlin
shouldInterceptRequest(...)
```

This allows the injected script to fetch models as if they were hosted on Instagram.

Supported types:

* `.js`, `.mjs`
* `.wasm`
* fallback: binary


## 🔄 End-to-End Flow

1. App launches
2. WebView loads Instagram
3. Page finishes loading
4. Kotlin injects `ai-overlay-engine.iife.js`
5. Script initializes inside DOM
6. Script:
    * Finds video elements
    * Loads ONNX/WASM models via `/_onnx/`
    * Runs inference through web worker (`ai-worker.iife.js`)
    * Applies visual transformations

## 🧩 Key Concepts

* WebView JavaScript injection
* Asset interception via `WebViewAssetLoader`
* IIFE bundling for sandboxed environments
* Client-side AI inference (ONNX + WASM) through web worker (`ai-worker.iife.js`)
